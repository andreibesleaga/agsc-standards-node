The node's own work on one board: the decision, the card format, the gate and the open tasks.

Members

  • Card format: What a card of this node must hold, stated so that tasks can follow it and a check can test it.
  • Cards are written in the node's own words: The decision that each card is a few lines in this node's own words, with a link to the document it describes.
  • Check the status of a document: Compare one card with the page of the body that publishes the document, and propose the result.
  • Check a published file against its digest: Compute the digest of one file of this node and compare it with the digest the discovery file gives.
  • Publish gate
  • Propose a document this node should describe: Name a published document that an agent-readable site builds on and that has no card here, with its address and status.
  • Re-check the AI usage preferences drafts: Read the current versions of the two IETF drafts and bring their card up to date, before 20 February 2027.
  • Re-check the working group on discovering agents: See whether the IETF working group has adopted a document, and bring its card up to date, before 18 February 2027.
  • Re-check the web bot authentication draft: Read the current version of the working group's draft and bring its card up to date, before 2 May 2027.
