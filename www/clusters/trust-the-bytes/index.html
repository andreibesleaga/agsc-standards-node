How a reader checks that a file is the one that was published, and who vouches for it.

Members

  • Digest fields (RFC 9530): HTTP fields that carry a hash of the message content or of the representation, so a receiver can check what it got.
  • HTTP message signatures (RFC 9421): A way to sign parts of an HTTP message, so a receiver can check who sent it and that it was not changed.
  • JSON canonicalization (RFC 8785): One fixed way to write JSON, so that equal data gives equal bytes before hashing or signing.
  • RDF dataset canonicalization: A W3C algorithm that gives one fixed form of an RDF dataset, so that it can be hashed or signed.
