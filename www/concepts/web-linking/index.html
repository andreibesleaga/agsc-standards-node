Web linking (RFC 8288)

SummaryTyped links between web resources, and the HTTP Link header field that carries them.

What it is

RFC 8288 defines typed links, each with a relation type that says what the link means, and the HTTP Link header field.

Status

IETF Proposed Standard, October 2017. It obsoletes RFC 5988. Status checked on 18 November 2026.

Why a site for agents uses it

A link that names its kind can be followed by a program without guessing.

Relations

An outgoing relation is stated by this item; an incoming one is a backlink, stated by the other item. Each meaning reads from the item that states the relation towards its target.

usesincomingLink sets (RFC 9264)This item draws on the target and can still be used when the target is absent.
